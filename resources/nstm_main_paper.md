Researchers have developed various structures, including meshes [19,35,--- PAGE 4 ---4 ECCV 2026 Submission #521743], multi-plane images [9,13–15], neural radiance fields [30,33, 46, 47, 51, 60, 61], point clouds [1, 45, 49, 56], 3D Gaussian splatting [21, 27, 54], etc. While effective, these representations impose implicit inductive biases that can constrain a model's flexibility when handling complex scenes that deviate from predefined priors.Recently, the field has shifted toward more general, data-driven architectures to reduce these geometric constraints [36,39]. One prominent direction leverages diffusion models [20], utilizing strong 2D generative priors to hallucinate unobserved regions within a 3D-aware framework [31, 32, 38, 52, 62]. In parallel, an emerging line of research demonstrates that constructing an explicit 3D proxy is not strictly necessary at all. Frameworks such as LVSM [23] and LaCT [64] operate in a purely representation-free manner by formulating NVS entirely as a latent sequence modeling task. Instead of building spatial structures, these methods tokenize source views and utilize expressive transformer architectures to implicitly capture multi-view consistencies. By directly predicting novel views in a feed-forward manner, they successfully bypass traditional 3D structural constraints and highlight the scalability of large vision models.2.2 Streaming Scene ReconstructionIn the context of dynamic environments, streamable novel view synthesis introduces unique complexities, requiring systems to operate causally and efficiently on continuous video streams. Unlike offline dynamic NVS methods that retrospectively optimize over the entire sequence [10, 16, 28, 29, 54, 57, 59], streaming reconstruction demands online updates using only current and historical frames under strict computational budgets. Early streaming approaches [40,58] rely on per-frame optimization, which is prohibitively slow for real-world applications. To accelerate this process, recent work [50] incorporates optical flow to reuse past information. However, this localized tracking mechanism inevitably accumulates errors over time, leading to long-term degradation. In our work, we address this limitation by encoding a persistent memory directly into the fast weights of the network [64]. This architecture allows our model to faithfully memorize scene geometry and retain historical context, ensuring robust, temporally consistent synthesis without cumulative drift.2.3 Memory ModulesTransformers [44] are the de-facto backbone of most recent advances in machine learning, ranging from language modeling [8,53] to computer vision [12] and video generation [23]. In recent years, however, there has been increasing interest in designing alternative sub-quadratic architectures, due to the prohibitive quadratic cost of Transformers on long-context data. A simple but elegant solution is to replace Softmax operator with a separable kernel [26], resulting in a linear attention with a recurrent computation and linear complexity that compresses the context into a fixed-size matrix-valued memory. Building on this concept, several studies explored improving linear attention architectures with incorporating: (1)--- PAGE 5 ---ECCV 2026 Submission #5217 5more powerful separable kernels [2,4,25,26]; (2) more expressive learning rules for better memory management such as Delta [37], Oja's [22], and Omega [4] rules; (3) different types of forgetting (or retention) gates [6, 18, 34, 42]; and (4) novel hybrid designs of Softmax attention and subquadratic architectures [2, 7, 11].Despite such advances, their fixed-size matrix-valued memory damages the performance of the models in retrieval-based tasks, mainly due to limited capacity of a linear matrix as the hidden state of the recurrent neural network. To this end, a new line of research starts designing methods based on "Test-time Memorization/Training" [6,41] and more generally Nested Learning [5] that allow the use of: (1) deep memory modules [7, 41] as the state of the recurrent models, where the memory capacity is proven to exponentially grow with the depth of the memory [4]; and (2) sub-linearly growing memory modules [3, 17] based on structured matrices [17] or memory caching [3], overcoming the fixed-size effective memory of such architectures. All these architecture designs, however, are limited to 1-dimensional sequential data, and so cannot take advantages of rich space-time dependencies in video data.3 MethodWe address online novel view synthesis from dynamic video streams. A standard block in TTT consists of a per-image self-attention module, a SwiGLU-MLP implicit memory module $(f_{W})$, and a standard feed-forward MLP. To interface with the memory, input tokens are projected into keys $k_{t}$, values $v_{t}$, and queries $q_{t}$. The memory internalizes context via a gradient-descent update on an inner loss to memorize the binding between $k_{t}$ and $v_{t}$ and is subsequently read via a forward query step $(o=f_{W}(q_{t}))$. Because disocclusion signals in streaming video are naturally sparse, the model tends to over-rely on the attention and effectively bypasses historical memory. To force the persistent internalization of scene context, we introduce an alternating training regime across a sequence of T timesteps.Memory Supervision: As illustrated in Fig. 2, on even timesteps $(t=0,2,...)$, we read out from the memory and supervise this readout to reconstruct a random target view. To enforce this loss on the memory alone, it is critical to ensure we read out purely from the memory, completely isolated from the current inputs. Therefore, we introduce additional memory readout tokens, representing the camera rays of the target view. Crucially, we restrict the attention mask of the aforementioned cross-view attention module such that these memory tokens only self-attend amongst themselves. These isolated tokens then query the updated memory and pass through the feed-forward layers. Ultimately, they form an image, denoted as $I_{t}^{mem}$, relying entirely on the internalized historical state. We note that the updates may miss events that happen between the updates. To avoid this issue, one could perform large chunk updates, which essentially perform the update step on multiple frames at a time, each with their own time embedding. This change would also enable the model to perform updates with irregular frame spacing (e.g. unsynced cameras on a multi-view rig). In general, this paper leaves open the question of which frames should be memorized. Future work could explore the tradeoff between more frequent updates and larger-chunk "batch" updates. Models like ours will eventually hit capacity limits and forget past observations. To improve persistence and stability, the model could learn scales for the weights in the memory cache in a similar fashion to other methods [3,65].5.2 ConclusionIn this work, we presented Neural Space-Time Memory (NSTM), a novel framework that bridges the gap between long-context memory and computational efficiency for dynamic novel view synthesis. By disentangling periodic memory updates from per-frame transformer-based deformation modeling, and introducing a targeted memory auxiliary loss, NSTM successfully internalizes persistent scene context while maintaining real-time speed. Furthermore, our memory caching strategy and stable $L_{2}$ update rule enhance long-term stability, unlocking minute-long memory horizons and achieving state-of-the-art results compared to existing baselines.ReferencesAliev, K.A., Sevastopolsky, A., Kolos, M., Ulyanov, D., Lempitsky, V.: Neural point-based graphics.
